# Bridger — Profile Question Bank

The full content for the Profile fill modules. This is the source of truth for questions (the equivalent of a `profile/quiz-data.ts`), referenced by `PROFILE.md`. Each module ends with the Review & share step (set-all + per-item visibility). Default visibility per module is noted; deeper/personal content defaults tighter.

**Fill order:** the basics and **Hobbies (Module 1A)** are surfaced first — hobbies are quick and fun to pick, so they get done "in a second" and give the profile instant personality — then the lighter modules, with deeper questions last. Hobbies also render at the **top** of the About me section.

**Display sections (where answers show on the Profile tab):** Header (photo, display name, profile song) · Ask me (friend-filled icebreakers, not owner) · About me (personal fields + important dates) · Hobbies (selected + follow-ups) · Unlocked quizzes (List of favs, Places traveled, This or that, Custom notes).

**Every module is answered with the baseline Typeform flow** — one question per screen, progress bar, smooth transitions, tappable / multi-select / image / this-or-that choices — the same feel as the onboarding basics and about-me questions (see "Module flow" in `ONBOARDING.md`). Filling favs or this-or-that should feel quick and playful, never like a dense form.

## Module 3 · Places Traveled
- Search / add places you've been.
- Per place tags: Visited · Lived there · Want to go
- Optional note per place
- Per-place visibility: who can see this?
- **Co-op: add photos per place.**

**Display:** a **two-view module** you swipe between (like the hobbies widget) — a **map with pins** and a **scrollable list** — contained within the widget. **Shared places surface both people's photos** in the In-common view for co-op members ("You've both been to France" → your photo + theirs). See `PROFILE.md`.

**Default visibility:** Everyone (or Friends).

## Module 4b · Bucket List
Things you want to do. Add as many as you like (one row each, Typeform-style):
- **Write the item** ("Learn to surf", "Hike the Inca Trail").
- **Tag friends (optional)** — mark it as something to do *together* (puts it on their radar; can surface in In-common when a friend shares the same want).
- **Public or private** per item (private = just you; public = friends per tier).
- Items can be **checked off** when done.

Stored on the profile; it's a **profile-only module** — you **add to it from the bucket-list module** (inline "+" with an "Add to your bucket list" null-state container). Not in any central menu.

**Default visibility:** per-item (you choose public/private as you add).

## Special step types (for the builder)

- **Multi-entry** (Family, Important dates): repeatable rows, each with its own fields.
- **Drag-order** (Birth order): reorderable list, oldest → youngest.
- **Derived** (Zodiac sun): can auto-fill from birthday.
- **Tag + note + per-item visibility** (Places traveled): each place carries tags, a note, and its own share level.
- **Deeper modules default to Close friends / Friends**; basics/fun default wider. The Review & share step's "set all" overrides per module, with per-item exceptions.
